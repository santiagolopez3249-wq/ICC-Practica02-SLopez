## Descripción
Simulador de inversión. La clase Fecha maneja fechas y la clase TiempoDeInversion calcula los días de una inversión y su rendimiento al 12%, en proporción a los días transcurridos entre las dos fechas.

## Estructura
SLopez/practica02/src/icc/
- Fecha.java
- TiempoDeInversion.java

## Compilar y ejecutar
Desde la carpeta `SLopez/practica02/src`:

javac icc/Fecha.java icc/TiempoDeInversion.java
java icc.TiempoDeInversion
(esto si es que se usa package icc; que lo use debido a que no sabía si es que se ejecutaría aquí o en otro programa externo)
